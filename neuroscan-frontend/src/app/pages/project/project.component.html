About the Project

This project develops and evaluates deep learning models for automatic classification of brain MRI scans into four categories: Glioma, Meningioma, Pituitary, and No Tumor.

The system delivers accurate predictions alongside model explainability (GradCAM, GradCAM++, LayerCAM) and comprehensive performance evaluation using multiple clinical metrics.
